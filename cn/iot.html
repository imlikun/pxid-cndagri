物联网 IOT，
让每一台车都在线

两轮车的智能化已经从卖点变成刚需——新国标把北斗定位列为整车出厂要求，租赁、换电、外卖与出海场景更是离不开车辆联网。PXID 在整车 ODM 里预留并集成车联网方案：车载终端、数据通道、云平台与 APP 一并规划，不让智能硬件变成量产后加装的补丁。

  • 4G Cat.1 + 北斗定位
  • 蓝牙无感解锁
  • 终端 / 整车 OTA
  • 开放云平台 API
端·管·云三层架构一层闭环
≤5m定位精度（CEP50）
IP67终端防护等级
9–120V宽压输入适配
01TELEMATICS BOX

车载智能终端 —— 整车的联网入口

通讯 / 定位 / 结构设计
01

车载智能终端（T-BOX）

TELEMATICS BOX
通讯4G Cat.1 全网通（移动 / 联通 / 电信）上报位置与车况，支持 MQTT 物联网协议；贴片 eSIM 免插卡，出海车型按目的国频段选配。
定位北斗 / GPS 双模定位，水平精度 ≤5m；冷启动 ≤35s、热启动 ≤5s；过滤算法剔除无效定位点，弯道轨迹补偿，停车静默低功耗。
近场蓝牙 5.x 与手机近场交互——无感解锁、远程锁车、一键寻车；靠近即连接，手机就是钥匙。
结构内置天线、备用锂电池（整车断电后可独立上报位移与告警）；9–120V 宽压输入同时适配铅酸与锂电平台；IP67 防护，体积按车头 / 座桶可藏空间设计。
标签4G Cat.1北斗 + GPS蓝牙 5.xeSIM 贴片备用电池IP67
02DATA CHANNEL

数据通道 —— 让终端读懂整车

总线协议 / 车况采集 / 异常上报
02

数据通道

DATA CHANNEL
总线终端通过 CAN 总线 / RS485 / 一线通与控制器、BMS、仪表建立数据通道——这套协议与三电系统页面的电控架构是同一套，集成时不加转换网关。
采集车速、电机功率与转速、电池电量电压温度、档位、故障码；本地循环覆盖存储，断网续传。
上报异常即时上报：超速、电池异常、非法位移、碰撞、倾倒、低电、防拆触发——平台与车主 APP 同步收到。
03SMART FEATURES

智能功能 —— 防盗、升级、骑行数据

按车型与运营场景选配
03

智能功能

SMART FEATURES
防盗多重定位智能防盗：北斗 + GPS + 网络定位互补，震动 / 倾倒 / 非法移动告警，电子围栏出区提醒，轨迹回放，鸣笛寻车。
升级终端 OTA + 整车控制器固件 OTA——功能不因出厂固化，bug 远程修复，新功能分批推送灰度验证。
骑行骑行数据与驾驶行为记录，车辆健康分析；运营场景下支撑车辆调度、风控评分与保险精算。
标签电子围栏震动 / 倾倒告警轨迹回放整车 OTA驾驶行为车辆健康
04CLOUD & APP

云平台与 APP —— 数据落到业务里

平台能力 / 车主 APP / 运营场景
04

云平台与 APP

CLOUD & APP
平台设备管理、位置服务、告警引擎、OTA 管理、数据看板；开放 API 对接车企自有的售后、运营与会员系统。
车主 APP远程解锁 / 锁车、车辆定位与轨迹、车况与电量查看、故障提醒、骑行统计——小程序与 APP 双端。
运营共享 / 租赁车队管理、换电与电池租赁、外卖车队监管；出海方案：eSIM 空中写卡、多国频段与本地资费适配，一点对接全球服务。

智能在整车项目里
一次做对

车联网不是整车做完再「加装一个盒子」。PXID 在 ODM 立项阶段就把终端位置、供电、天线布局、总线通道与仪表显示一起排进整车方案——样车阶段联网功能与三电同步联调，量产后通过 OTA 持续迭代。合规要求（如新国标北斗定位）、运营需求（租赁 / 换电）、出海认证，在选型时就定掉。
