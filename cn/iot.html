Overview

让每一辆车，都连在云上

IOT 模块是整车的联网入口：把位置、电量、故障与骑行行为实时上传云端，运营方在后台就能看到每一辆车的健康度——共享调度、换电提醒、防盗追踪，一套数据全打通。

Hardware

一颗模组，接入整车

IOT 模组作为 CAN 节点与控制器 / 仪表对接，无需改动车型主电路。

  • 标准 CAN 接口，即插即用
  • 4G + BLE 双模冗余
  • 宽压供电，适配全平台
Platform

一套云端，管整支车队

开放 API 对接客户的调度、换电与 CRM 系统，数据所有权归运营方。

  • 实时资产看板
  • 续航预测与换电提醒
  • 分级权限 + 加密通道
