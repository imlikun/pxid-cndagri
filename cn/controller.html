项目模块需准备的资料 / 关键信息影响的决策参考示例
电池平台提供能量基础
  • 电池类型（锂电 / 铅酸等）
  • 电压范围与标称电压
  • 最大持续 / 峰值放电电流
  • BMS 通信协议（如有）
  • 控制器电压等级选型
  • 电流规格与过流能力
  • 欠压 / 过压保护策略
  • 通信兼容性

  • 电机类型（永磁同步 / 异步等）
  • 额定功率 / 峰值功率
  • 额定转速 / 最高转速
  • 电机参数（电感、电阻、极对数等）
  • 控制算法与驱动模式
  • 电流环 / 速度环参数范围
  • 匹配的控制器型号
  • 散热与功率冗余设计
例如：
永磁同步电机 15kW
额定转速 3000rpm
极对数 4，线电阻 12mΩ
整车工况定义应用边界
  • 整车类型（AGV / 工程机械 / 两轮车等）
  • 整车重量 / 载重
  • 最高车速 / 加速度要求
  • 典型工况（爬坡、复杂路况、连续作业等）
  • 控制策略与功能配置
  • 功率与散热冗余
  • 可靠性与防护等级
  • 制动与能量回收策略
例如：
工程车，整备质量 1200kg
最高车速 40km/h
爬坡 30%，连续作业 2h
接口与空间匹配安装条件
  • 高压 / 低压接口定义
  • 通信接口（CAN / RS485 等）
  • 安装尺寸与布置空间
  • 冷却方式（风冷 / 水冷 / 自然冷却）
  • 接口兼容与线束方案
  • 控制器尺寸与安装方式
  • 散热设计与环境适应性
  • 整车布置与维护便利性

FAQ

常见问题

整理用户最关心的问题，帮助您快速获取关键信息。

01PXID 控制器支持哪些车型？

需根据车辆类型、动力平台与使用工况逐项核对。请提供整车资料，由项目团队评估适配边界。

02如何确认控制器与我的车辆匹配？

建议先确认电池、电机、整车工况以及接口和安装空间，再进行样件匹配与样车验证。

03是否提供技术资料与测试报告？

对应型号的规格、接口与验证资料请联系项目团队索取；可提供的范围以正式文件为准。

04可以提供定制化开发支持吗？

可将需求与现有整车信息提交给项目团队，双方评估开发范围、周期与交付条件。
