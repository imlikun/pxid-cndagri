THREE-ELECTRIC SYSTEM

电机、控制器、仪表，
整车动力一套匹配

一台电动自行车或电动摩托车好不好骑，动力取决于三件事：电机出多大扭矩、控制器给多大电流、仪表把哪些信息讲清楚。PXID 按 ODM 整车项目做三电选型与系统匹配——三个部件在一个方案里定下来、在一台样车上联调，不拿现货拼凑。

  • 电机 · 控制器 · 仪表 一体匹配
  • 36V–72V 电压平台
  • FOC 矢量控制
  • CAN / 一线通 通讯

01CONTROLLER

控制器 —— 整车的动力分配与安全保护

技术方案 / 平台与通讯 / 保护与合规
01

控制器

CONTROLLERMCU × FOC
做什么把电池的直流电，按转把指令与整车状态调制成驱动电机的三相电流，精确控制转速与扭矩；整车的电气保护、能量回收、灯光供电大多挂在这块板子上。
技术FOC 正弦波矢量控制替代传统方波——噪音更低、低速更平顺、全速段效率更高。32 位车规级 MCU 配三相全桥 MOSFET 拓扑，峰值相电流按车型定位配置；支持有感（霍尔）与无感方案，上电自动识别电机相位角。
平台36V / 48V / 60V / 72V 常用电压平台。与仪表、BMS 之间走 CAN 总线或一线通通讯，预留蓝牙、4G 模块扩展位；控制器固件支持 OTA 升级，售后可读取故障码。
保护过流、过压、欠压、MOS 过温、电机过温、堵转、短路、反接、防飞车全套保护；刹车断电与滑行/制动能量回收；三档变速、定速巡航、倒车、助力（PAS）模式可配置。铝合金压铸外壳，防护等级 IP65–IP67，按出口市场做 EMC 合规设计。
标签FOC 正弦波CAN · 一线通OTA 升级能量回收PAS 助力IP67 可选
02METER

仪表 —— 骑手与整车之间的人机交互

屏幕 / 显示与诊断 / 互联与防护
02

仪表

METER / DISPLAYTFT × CAN
做什么与控制器实时通讯，把车速、电量、续航估算、助力档位、故障信息呈现给骑手；同时承担灯光、档位切换、模式选择这些操作入口。仪表是整车的人机交互中枢，不只是显示屏。
屏幕从 LCD 段码屏到 3.5–5 英寸 TFT 彩屏（主流分辨率 480×800）按成本档位选型；自动背光调节——白天日光下可读、夜间骑行不刺眼。
显示实时 / 最大 / 平均速度，剩余电量与续航估算，单次与累计里程，电机功率输出；手把、控制器、电机、刹车异常实时提示，故障码支持售后设备读取。
互联蓝牙 5.0 连接手机 APP——骑行数据同步、参数自定义、导航投屏；Type-C USB 充电口给手机补电；防护 IP65–IP66，-30℃–80℃ 宽温工作；公里/英里切换与多语言界面，适配出口市场。
标签TFT 彩屏CAN · UART自动背光蓝牙 APP故障自诊宽温 -30~80℃

03

电机

MOTORBLDC / PMSM
HUB MOTOR
轮毂电机

电机直接集成在车轮内，动力零传动损耗，结构简单、免维护，成本友好。城市通勤车、共享车型、滑板车的主流选择。

250W–2000W+巡航效率 85–90%免维护密封前后轮均可布置
MID-DRIVE
中置电机

布置在车身中部，经链条或皮带驱动后轮，重心居中、操控与攀爬表现好，可借变速系统放大扭矩。高性能电摩与越野车型的首选。

2000W–5000W峰值扭矩至 130Nm重心居中配变速放大扭矩
参数BLDC 无刷 / 永磁同步（PMSM）为主流路线；48V–72V 电压平台，额定功率与峰值扭矩按车型配置；霍尔 / 编码器双重位置反馈可选；电机本体 IP54–IP67 密封防护，静音设计。
匹配电机与控制器、减速比、轮组同步选型——同一台车换电机路线，控制器电流与仪表显示逻辑都要跟着调，这也是三电要一套方案定的原因。
SYSTEM MATCHING

三电不是三件配件，
是一套匹配好的系统

在 ODM 项目里，三电按整车需求反推：先定车型与目标市场——合规车速、载重、续航目标；再定电机功率与扭矩、控制器电流与保护策略、仪表显示与交互；最后在同一台样车上联调。打样阶段三电与车架同步迭代，不让续航虚标、过热降功率这类问题拖到量产后才暴露。

  • 按车型反推参数
  • 样车联调验证
  • 故障码可售后读取
  • 固件可持续 OTA
